# TagFin Landing Page

This is the landing page for **TagFin**, a smart Slack message tagging app.

## 🚀 Tech Stack
- Vanilla HTML5 & CSS3
- Frosted glass effect (modern UI)
- Fully responsive
- Deploy-ready on Vercel or Netlify

## 📦 Files
- `index.html` — main landing page
- `styles.css` — theme styling (dark + frosted UI)
- `logo.png` — your brand image

## 🚀 Quick Deploy
- Push to GitHub
- Import in [Vercel](https://vercel.com/) or [Netlify](https://netlify.com/)
